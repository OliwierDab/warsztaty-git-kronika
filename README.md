# Dzień Otwarty CKZiU — dokumentacja wydarzenia

To jest repozytorium ćwiczeniowe do nauki systemu kontroli wersji Git.

W repozytorium będą przechowywane wyłącznie proste pliki tekstowe `.txt` i `.md`.

## Cel projektu

Przygotować dokumentację organizacyjną fikcyjnego wydarzenia szkolnego.

## Pliki w projekcie

- `opis-wydarzenia.md` — ogólny opis wydarzenia,
- `plan-stanowisk.txt` — lista stanowisk i odpowiedzialności,
- `harmonogram.md` — plan godzinowy,
- `notatki.txt` — robocze notatki zespołu,
- `docs/zasady-pracy.md` — zasady pracy zespołu.
